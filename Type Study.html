Brand study

Headline type, post-Numberline.

Current system: Figtree 800 headlines, all-caps NUMBERLINE wordmark, Plus Jakarta Sans body. The question: what moves the site toward Mercury / Slack / "the future" territory? Body + UI text stays Plus Jakarta Sans in every option below — this study only changes headlines and the wordmark.

What the reference brands actually do

Mercury, Slack, and Linear get their modern feel less from exotic fonts and more from typographic restraint:

Weight restraint

Headlines at 500–700, never 800+. Confidence comes from size and space, not boldness. Our 800 everywhere reads loud.

Bigger, tighter, calmer

Larger sizes, tighter tracking (−0.03 to −0.04em), snug leading, generous whitespace around the block.

Sentence case + lowercase marks

slack, mercury, stripe, linear — wordmarks are lowercase or sentence case. All-caps + letterspacing reads institutional.

One voice

A single grotesk carries the brand. Character comes from a few distinctive letterforms, not decoration.

The wordmark case question

Independent of font choice, this is the single biggest brand-age signal. Shown in Schibsted Grotesk:

TodayNUMBERLINEAll-caps + letterspacing: institutional, telecom-legacy. Reads like the incumbents Numberline replaces.
ProposednumberlineLowercase, tight: the slack/mercury/stripe convention. Also literally on-brand — a number line is lowercase, horizontal, continuous.

Recommendation

C + the manners from B, in this order:

  1. Lowercase the wordmark (biggest signal, zero redraw — the tick-mark glyph already works at lowercase x-height).
  2. Drop headline weight 800 → 700, tracking −.03em → −.035em, and let hero sizes grow ~10%. Applies whichever font wins.
  3. Swap headlines to Schibsted Grotesk — Mercury-grade character, distinct from every competitor, pairs cleanly with Plus Jakarta body.
  4. Keep: Plus Jakarta for body/UI, Spline Sans Mono eyebrows, ink-only headlines, the function color system — those already read modern.
