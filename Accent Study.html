Picking the accent.

The current aqua reads much brighter than the function palette it sits beside - those chips are pale pastel washes, so a near-neon accent breaks the tonal family. Below, each candidate is shown in real context: hero chip, check marks, and black CTAs, with the six function chips right next to it so you can judge harmony rather than the swatch alone.

Direction 2 - keep the neon, bring everything up to it

You're right that dimming the accent is the coward's fix. The other way to resolve it: the accent isn't too bright, the function palette is too washed out. Re-cut all six at the same electric saturation and the aqua stops looking like an outlier. This is a bolder, more memorable system - and much harder to confuse with any other phone company.

Direction 3 - a different hue entirely

Fair point on B: pale mint is wellness-brand territory. If teal is the problem rather than the brightness, these have more edge. Each shown neon-bright, since that's the energy level that works.

How many colors does the routing card need?

The six rows are a sequence, not six things you must tell apart. The icon and label already name each function, so hue adds nothing - and six saturated hues cancel each other out, leaving no focal point. But stripping color entirely reads as disabled, which is worse. The fix isn't less color, it's fewer roles for color: give the icons one job (be the brand) and the chips one job (be the outcome).

Note this conflicts with the standing rule that a function keeps its color everywhere it appears. That rule earns its keep when a function shows up in isolation or mixed with others - a destination chip in a routing diagram, a badge in the app - where color genuinely helps you spot it. In an ordered list of all six, it does the opposite. My suggestion is to scope the rule to those cases rather than drop it.

Recommendation

Direction 2 - keep #A2FBEF and re-cut the function palette to match. Softening the accent solves the clash by removing the personality, and lands exactly where you don't want to be. Black wordmark, black CTAs, and one electric aqua is a sharper, more confident system than black plus six pastels. If you want to move off teal, Acid Lime #D8FF57 is the strongest alternative - same voltage, reads as utility and signal rather than spa.
